One short, funny rant about the self-checkout machine accusing you of stealing the crisps it watched you scan two seconds earlier — 347 characters, 4 sentences, 1 bag of crisps, 1 bored teenager, 0 crimes committed.

## The rant

> I bought three things - three - and the self-checkout scanned two, then screamed 'UNEXPECTED ITEM IN THE BAGGING AREA' at a bag of crisps it had just watched me scan. Now I'm standing there, hands up like a suspect, while a teenager strolls over at the speed of a software update to press one button. I could have queued for a human. I chose this.

## Why this angle

The self-checkout alarm is a shared, specific, everyday humiliation: the machine is the only witness to your innocence and it still reports you. The rant stays on one concrete moment — three items, one false accusation, one slow rescue — with no throat-clearing and no list of complaints. The anger is the shopper's, not a performance: hands up like a suspect, then the quiet self-blame of the last two sentences.

## How to run

Requires Python 3.13 (any Python 3 works — no dependencies).

```sh
python3 main.py
```

This writes the rant to `/output/entry.txt`. To write elsewhere, set `MAKEFUN_OUTPUT`:

```sh
MAKEFUN_OUTPUT=/tmp/out/entry.txt python3 main.py
```

The rant is a literal string in `main.py`, so the output is byte-identical on every run.
